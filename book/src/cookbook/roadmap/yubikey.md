# Use a YubiKey

**Not yet available.** Planned for a later phase ([roadmap](../../../../README.md#roadmap)).

A YubiKey becomes a recipient that unlocks the vault and signs approvals with a PIN or touch, and a route can ask for a
touch on each request.

Until then, unlock and approval use passphrases, and a config with a route that asks for a touch is refused when it is
read.
